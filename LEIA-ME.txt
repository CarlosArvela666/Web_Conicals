CRÓNICAS WEB — PACOTE PORTÁTIL WINDOWS x64

1. Extrai a pasta incluída no ZIP para um local com permissões de escrita.
2. Executa CronicasWeb.exe. O Node é incluído; não é necessário instalar Node.
3. O iniciador abre o DM no navegador e fica no tabuleiro do sistema.
4. Botão direito no ícone para abrir DM, projetor, Player 1–6 ou sair.
5. Os endereços escolhidos pelo iniciador ficam em data\connection.txt. Usa o IPv4 do anfitrião
   e acrescenta /player/1 até /player/6 ou /projector para os outros dispositivos.

Os dados da campanha ficam em data\campaign.json, junto da aplicação, e os mapas,
retratos e músicas ficam dentro de data\. Mantém esta pasta inteira e faz cópias de segurança.
As campanhas adicionais ficam em data\campaigns e são gravadas automaticamente. O DM pode
ocultar ou revelar jogadores para as vistas públicas; cada jogador continua a ver a própria ficha.
Este executável é para Windows x64. Outros sistemas/dispositivos participam pelo navegador.
